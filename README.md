# 🎬 Movie Review Application - Spring Boot Backend

This repository contains the backend service for the Full-Stack Movie Review Application, built using Spring Boot. It exposes the REST API endpoints necessary for the React frontend to fetch movie data and submit user reviews.

---

## 🚀 Technology Stack

| Component | Technology | Version | Description |
| :--- | :--- | :--- | :--- |
| **Framework** | **Spring Boot** | 3.x | Core framework for building the REST API. |
| **Language** | **Java** | | Primary language for server-side logic. |
| **Database** | **MongoDB** | | NoSQL database used for persistent storage of movies and reviews. |
| **Build Tool** | **Maven** | | Dependency management and build automation. |

---

## ⚙️ Prerequisites

Before running the application, ensure you have the following installed:

1.  **Java Development Kit (JDK):** Version 17 or higher.
2.  **Maven:** For building the project.
3.  **MongoDB:** A running local or remote instance of the MongoDB database.
